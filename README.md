## 📂 Featured Project

### 📦 StockFlow — Inventory & Sales Management

A full-stack web application for managing products, customers, suppliers, inventory movements, and sales.

**Key features:**

- 🔐 JWT authentication and role-based authorization.
- 📦 Product and inventory management.
- 🛒 Sales tracking and stock movements.
- 📊 Dashboard and operational reports.
- 🧪 329 automated tests across frontend and backend.
- ☁️ Deployed using Vercel, Render, and Neon PostgreSQL.

**Tech stack:** `Java` · `Spring Boot` · `React` · `TypeScript` · `PostgreSQL` · `Docker`
