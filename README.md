## 📂 Some Projects

Here are some projects I've worked on individually and collaboratively.

### 📦 StockFlow — Inventory & Sales Management System

A full-stack web application developed to manage inventory and sales operations through a modern and intuitive interface.

The system allows users to manage **products, categories, suppliers, customers, stock entries and exits, and sales**. It also includes a dashboard with operational indicators and reports.

The application implements **JWT authentication, role-based access control, REST APIs, and automated testing**.

**Technologies:** `Java` `Spring Boot` `Spring Security` `PostgreSQL` `React` `TypeScript` `Docker`

**Project Links:**

- 💻 [Frontend Repository](https://github.com/Mateo1744/stockflow-frontend)
- ⚙️ [Backend Repository](https://github.com/Mateo1744/stockflow-api)
- 🌐 [Live Application](https://stockflow-frontend-sigma.vercel.app/login)

*A public demo account with limited permissions is available in the frontend repository.*

### 🤟 Real-Time Sign Language Recognition

An academic project focused on developing a web application for recognizing sign language alphabet gestures in real time using **artificial intelligence and computer vision**.

The application processes hand gestures captured through a camera and uses a trained machine learning model to identify letters and help users form words.

This collaborative project explores the integration of **gesture recognition, image processing, and web technologies**.

**Technologies:** `Python` `Flask` `TensorFlow` `Keras` `MediaPipe` `OpenCV` `MongoDB`

**Project Link:**

- 💻 [GitHub Repository](https://github.com/paola2244/Real-Time-Sign-Language-Recognitio)

*Academic collaborative project. Repository hosted by a project collaborator.*
